# Glossary

```{glossary}
Work
  The citable unit in Curvenote: an article, notebook, dataset,
  thesis, or similar. A work has a stable identity and many
  immutable versions.

Version
  An immutable snapshot of a work. Versions are individually
  addressable and can be cited and assigned a DOI.

Site
  The public web presence for one or more works. A site is built
  from a repository of MyST markdown and notebooks.

Venue
  Synonym for journal. A publication that accepts submissions and
  publishes works under its own brand.

Journal
  See *venue*.

Submission
  A work that has been submitted to a venue and is flowing through
  the editorial pipeline.

Check
  A validation that runs against a work — metadata completeness,
  link integrity, license presence, accessibility, and so on.

Linked account
  An external identity (GitHub, GitLab, ORCID, Google, Okta) that
  has been associated with a Curvenote user account.

SCM
  Source control management. Curvenote integrates with GitHub and
  GitLab as the primary content sources.

Plugin
  A package that extends Curvenote with custom directives, checks,
  or build steps. Plugins build on the MyST plugin model.

MyST
  Markedly Structured Text. The markdown flavor and tooling that
  Curvenote authoring is built on. See https://mystmd.org.
```
