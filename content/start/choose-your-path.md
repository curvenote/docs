# Choose your path

Curvenote has several distinct surfaces. The fastest way to find what
you need is to start from your role.

## Researcher / Author

You want to write a paper, thesis, or report and publish it on the web
with good metadata, citations, and a DOI.

1. [Sign in and link accounts](/platform/getting-started/sign-in)
2. [Connect a repository](/platform/getting-started/connect-repo)
3. [Publish your first site](/platform/getting-started/first-site)
4. [Versioning a work](/platform/works/versioning)
5. [DOIs and archival](/platform/works/dois)

## Journal editor / Venue admin

You run a publication and want to accept submissions, run editorial
review, and mint DOIs.

1. [Journals concepts](/platform/journals/concepts)
2. [Setting up a journal](/platform/journals/setup)
3. [Submission workflow](/platform/journals/submission-workflow)
4. [Editorial review](/platform/journals/editorial-review)
5. [Publishing and DOI minting](/platform/journals/publishing)

## CLI user / Self-hoster

You want to build sites locally, run checks in CI, or self-host pieces
of the stack.

1. [Install the CLI](/cli/install)
2. [CLI tutorial](/cli/tutorial)
3. [Configuration](/cli/config)
4. [CI/CD recipes](/cli/ci)
5. [Command reference](/cli/commands/)

## Plugin author / Contributor

You want to extend Curvenote with a custom MyST directive, a custom
check, or contribute to the platform itself.

1. [Plugin overview](/extend/plugins)
2. [Custom MyST directives](/extend/directives)
3. [Custom checks](/extend/checks)
4. [Architecture overview](/architecture/system-overview)
5. [Contributing](/architecture/contributing)
