# Extend

Curvenote is built on top of MyST and exposes the same plugin model
for extension. You can add custom MyST directives, custom checks, or
full plugins that hook into the build pipeline.

- **[Plugin overview](./plugins.md)** — the plugin model and how
  plugins are loaded.
- **[Custom MyST directives](./directives.md)** — add new directives
  and roles.
- **[Custom checks](./checks.md)** — author check definitions and
  implementations.
- **[Publishing a plugin](./publishing.md)** — package and distribute.
